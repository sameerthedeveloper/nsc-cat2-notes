# NSC CAT-2 notes

Revision site for CSD 3103 Network Security and Cryptography, CAT-2 (Module III public key cryptography, Module IV message authentication and hash functions).

- 17 topics: definition, working, diagrams, worked numericals, 2/5/8/16-mark answers.
- October 2025 paper solved in full.
- Live calculators: RSA, Diffie–Hellman (with a man-in-the-middle switch), elliptic curve points, MD5/SHA hash lab with avalanche count, HMAC, modular inverse.
- Puter.js AI tutor (free Puter sign-in), day/night theme, mobile layout.

```bash
npm install
npm run dev
npm run build
```

Same UI as the TOC and AI sites. No video lessons yet.
